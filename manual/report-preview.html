Chapter 6: レポートプレビュー

レポートのプレビュー、保存・PDF 出力（Pro）

レポート画面の概要

結果画面の「レポートプレビュー」で、診断結果をレポート形式でプレビューできます。レポートのプレビューと保存・PDF 出力は Pro で利用できます。Free 版では「レポートプレビュー」ボタンは無効です。

レポートプレビュー画面

レポート（Pro 版） Pro

Pro 版では、診断結果のレポートをプレビューできます。レポートプレビューには以下の節があります。

  • 対策状況に不足がある項目
  • CSF カバレッジ
  • 主要リスク
  • 想定攻撃シナリオ
完全レポートのプレビュー — 攻撃シナリオ（Pro 版）

PDF 出力と保存 Pro

Pro 版では、レポートを PDF ファイルとして出力できます。HTML / Markdown での保存も Pro 版で利用できます。

  1. レポートプレビュー画面で内容を確認します。
  2. レポートプレビュー画面の「PDF 出力」ボタンをクリックします。
  3. 保存先を選択すると、PDF ファイルが生成されます。

PDF 出力には WebView2 Runtime が必要です。インストールされていない場合は別途インストールしてください。詳しくはトラブルシューティングを参照してください。

Chapter 6: Report Preview

Report preview, saving and PDF export (Pro)

Report Screen Overview

The Report Preview screen, opened with "Report preview" on the Results screen, shows the assessment results in a report format. Preview, saving, and PDF export are available in Pro. In the Free edition, the "Report preview" button is disabled.

Report preview screen

Report (Pro Edition) Pro

The Pro edition lets you preview the full report. The report preview includes the following sections:

  • Items with gaps in control status
  • CSF Coverage
  • Key Risks
  • Attack Scenarios
Full report preview — attack scenarios (Pro edition)

PDF Export and Saving Pro

The Pro edition allows you to export reports as PDF files. Saving as HTML / Markdown is also available in Pro.

  1. Review the content on the Report preview screen.
  2. Click the "Export PDF" button on the Report Preview screen.
  3. Select a save location and the PDF file will be generated.

PDF export requires the WebView2 Runtime. If it is not installed, install it separately. See Troubleshooting for details.
