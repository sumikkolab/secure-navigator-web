Pro で追加される主な機能

追加フレームワーク参考確認

Free 版では IPA 中小企業向けガイドラインを参考にした確認を利用できます。Pro 版では経済産業省のサイバーセキュリティ経営ガイドラインおよび NIST Cybersecurity Framework 2.0 を参考にした対応状況の表示も利用できます。

Free版でのフレームワーク選択（ロック表示）
Pro版：NIST CSF 2.0 参考確認

ATT&CK テクニックの詳細

Pro 版では、各テクニックの詳細（セルの展開・詳細ペイン）を確認できます。Free 版でも、戦術ごとのカバレッジと状況別の群は確認できます。

Free版での攻撃ビュー制限表示

レポートのプレビュー・保存・PDF 出力

Pro 版では、レポートをプレビューし、HTML / Markdown や PDF ファイルとして保存できます。レポートには、対策状況に不足がある項目、CSF カバレッジ、主要リスク、想定攻撃シナリオの節が含まれます。

複数セッション

Free 版では診断セッションを1件のみ保存できますが、Pro 版では最大3件まで保存可能です。複数の組織や部門の評価を並行して管理したり、時期を変えて同じ組織を再評価して改善の進捗を確認する際に便利です。

アップグレード方法

  1. 設定画面を開き、「Pro にアップグレード」を選びます。
  2. Microsoft Store での購入を完了します。
  3. 購入後に Pro が反映されない場合は、設定画面の「復元」で購入情報を確認します。

Pro へのアップグレード後は、追加のガイドライン参考確認やレポート機能が利用可能になります。

What Pro Adds

Additional Framework Reference Checks

While the Free edition supports reference checks using the IPA SME Guidelines, Pro adds status views using the METI Cybersecurity Management Guidelines and NIST Cybersecurity Framework 2.0 as reference material.

Framework selection in Free edition (locked)
Pro edition: NIST CSF 2.0 reference check

ATT&CK Technique Detail

Pro provides the details of each technique (expandable cells and a detail pane). The Free edition still shows the coverage for each tactic and the status groups.

Attack view restriction in Free edition

Report Preview, Saving, and PDF Export

Pro lets you preview the report and save it as HTML / Markdown or a PDF file. The report includes sections for items with gaps in control status, CSF coverage, key risks, and attack scenarios.

Multiple Sessions

The Free edition allows saving 1 assessment session, while Pro supports up to 3. This is useful for evaluating multiple organizations or departments in parallel, or re-assessing the same organization at different times to track improvement progress.

How to Upgrade

  1. Open the Settings screen and select "Upgrade to Pro".
  2. Complete the purchase in the Microsoft Store.
  3. If Pro is not reflected after purchase, use "Restore" in the Settings screen to re-check your purchase.

After upgrading to Pro, additional framework reference checks and report features become available.
