Chapter 3: 質問への回答

ホーム、個別型・リスト型の回答画面、回答選択肢、ナビゲーション

ヒアリング画面の概要

ヒアリング画面に入ると、最初に「ホーム」が表示されます。ホームから、1 問ずつ回答する「個別型」と、全テーマの質問を行で並べて続けて回答する「リスト型」のどちらかに進みます。「結果を見る」で結果画面に進めます。回答済みの質問が全体の 25% に達すると、回答の途中でも暫定の結果を確認できます（25% 未満では結果は表示されません）。80% 以上で確定の結果になります。回答は 1 問ごとに自動で保存されます。回答画面は、開くたびに最大化で表示されます。タイトルバーの「元に戻す」を選ぶと、開いている間だけ通常の大きさに切り替えられます。

ホーム

ホームでは、全体の進捗と、次の操作が表示されます。

  • 全体の進捗: 回答済みの数を確認できます。
  • つづきから再開: 前回の続きから回答を再開します。
  • リスト型で回答: 「リスト型」の画面に進みます。
  • 個別型で回答: 「個別型」の画面に進みます。
  • 未回答だけ見る: 未回答の質問に絞って表示します。
  • テーマごとのカード: テーマごとに進捗（未着手・途中・完了）が表示されます。各テーマのカードで「この項目の質問に移動」を選ぶと、そのテーマの質問に進みます。
ホーム

カード UI（個別型）

「個別型」では、各質問がカード形式で 1 問ずつ表示されます。カードには質問テキスト、所属するテーマ名、および回答選択肢が含まれます。「回答後に自動で次へ」をオンにすると、回答後に自動で次の質問に進みます。

個別型

回答選択肢

各質問に対して、以下の4つの選択肢から回答を選びます。

選択肢意味
実施済み実施済みと判断できる場合。
一部実施一部のみ実施している場合。
未実施未実施と判断できる場合。
未確認まだ確認できない場合。

「後で確認」にチェックを入れた質問は、「未回答・後で確認」の一覧でまとめて確認できます。一覧は「未回答または後で確認」「未回答のみ」「後で確認のみ」で絞り込めます。

ナビゲーション

ヒアリング画面では、以下の方法で質問間を移動できます。

  • ホーム: テーマごとのカードから、任意のテーマの質問に移動できます。
  • 戻る / 次へボタン: 「個別型」で、前の質問や次の質問に移動します。
  • テーマのチップ: 「個別型」と「リスト型」のどちらでも、画面上部のチップからテーマを選べます。
  • 行の移動: 「リスト型」で、↑↓・PageUp / PageDown による移動ができます。
  • 進捗表示: 全体とテーマ内の進捗が表示されます。
未回答レビューウィンドウ

表示：個別型とリスト型

質問画面には、「個別型」と「リスト型」の 2 つのタブがあります。タブで切り替えられます。

個別型

1つの質問だけを画面に大きく表示するモードです。集中して1問ずつ回答したい場合に適しています。「戻る」「次へ」で前後の質問に移動し、「このテーマの質問」で同じテーマの質問を確認できます。

リスト型

全テーマの質問を 1 行ずつ並べて表示するモードです。各行の回答ボタンを押すと、続けて回答できます。

リスト型
  • テーマのチップ: 画面上部のテーマ名のチップ（「回答済み/全体」の件数つき。すべて回答したテーマには完了の印）は、個別型でも表示されます。リスト型では、選ぶとそのテーマの行に絞り込めます。個別型では、選ぶとそのテーマの未回答の質問（なければ先頭の質問）に移動します。
  • 未回答だけ表示: オンにすると、未回答の質問だけが表示されます。
  • キー操作: 下の表のキーで、マウスを使わずに回答できます。
キー動作
1〜4回答して次の行へ移動します（同じキーをもう一度押すと取り消し）。
↑ ↓行を移動します。
PageUp / PageDownテーマを移動します。
H「後で確認」にします。
Space / Enter / F1この質問についての説明を表示します。
Esc説明を閉じます。

「後で確認」機能

今すぐ答えられない質問には、「後で確認」にチェックを入れておきます（リスト型では H キー）。チェックした質問は、「未回答・後で確認」の一覧でまとめて確認できます。

Chapter 3: Answering Questions

Home, single-question and list modes, answer options, navigation

Hearing Screen Overview

When you open the Hearing screen, the Home screen appears first. From Home, go to Single-question mode, which shows one question at a time, or List mode, which lists the questions of all themes in rows so you can answer them one after another. Select "View results" to proceed to the Results screen. Once 25% of all questions are answered, a provisional result is available even before the rest are answered. Below 25%, no result is shown. At 80% or more, the result becomes final. Each answer is saved automatically. The answer screen opens maximized every time. Select the restore button on the title bar to switch to the normal size while it is open.

Home

Home shows your overall progress and what to do next.

  • Overall progress: Shows how many questions you have answered.
  • Resume: Continues from where you left off.
  • Answer in list mode: Opens List mode.
  • Answer in single-question mode: Opens Single-question mode.
  • Show unanswered only: Narrows the questions down to those that are unanswered.
  • Theme cards: Each theme shows its progress (Not started, In progress, or Done). Select "Go to questions in this section" on a theme card to go to the questions of that theme.
Home

Card UI (Single-question mode)

In Single-question mode, each question is displayed as a card, one at a time. The card contains the question text, the theme it belongs to, and the answer options. When the automatic-advance option is turned on, the next question is displayed automatically after you answer.

Single-question mode

Answer Options

For each question, select one of the following four options.

OptionMeaning
ImplementedChoose when this is implemented.
Partially ImplementedChoose when only partly implemented.
Not ImplementedChoose when not implemented.
UnverifiedChoose when you cannot verify yet.

Questions marked "Review later" can be reviewed together in the "Unanswered & review later" list, which you can filter to show unanswered questions, review-later questions, or both.

Navigation

The Hearing screen provides multiple ways to navigate between questions.

  • Home: Use the theme cards to go to the questions of any theme.
  • Back / Next buttons: In Single-question mode, move to the previous or next question.
  • Theme chips: In both Single-question mode and List mode, choose a theme from the chips at the top of the screen.
  • Row movement: In List mode, move with Up / Down and PageUp / PageDown.
  • Progress: Overall progress and progress within the theme are shown.
Unanswered review window

Modes: Single-question and List

The question screen has two tabs, Single-question mode and List mode. Switch between them with the tabs.

Single-question mode

Displays one question at a time on the screen. This view is ideal for concentrating on each question individually. Use "Back" and "Next" to move between questions, and the theme's question list to see the other questions of the same theme.

List mode

Lists the questions of all themes, one per row. Select an answer button on a row to keep answering one question after another.

List mode
  • Theme chips: The theme chips at the top of the screen (each with its answered/total count, and a check mark once every question is answered) also appear in Single-question mode. In List mode, select a chip to narrow the rows down to that theme. In Single-question mode, select a chip to go to the first unanswered question of that theme (or its first question if all are answered).
  • Show unanswered only: When turned on, only unanswered questions are shown.
  • Keyboard: Use the keys in the table below to answer without the mouse.
KeyAction
1-4Answer and go to the next row (press the same key again to undo).
Up / DownMove between rows.
PageUp / PageDownMove between themes.
HMark for later review.
Space / Enter / F1Show information about this question.
EscClose the information.

Review Later

If you cannot answer a question right away, mark it as "Review later" (press H in List mode). Marked questions can be reviewed together in the "Unanswered & review later" list.
