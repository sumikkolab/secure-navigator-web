Chapter 7: 設定

言語切替、ライセンス、外部リンク

設定画面の概要

設定画面（ダイアログ）では、表示言語・ライセンス・外部リンクなどを確認できます。メイン画面の設定ボタンから開きます。

言語の切替

SecureNavigator は日本語と英語に対応しています。設定画面の「表示言語」で、「日本語」「English」から選択できます。

表示言語の変更は、以下に反映されます。

  • アプリケーション全体の UI テキスト
  • ヒアリング画面の質問文と回答選択肢
  • 結果画面の表示内容
  • レポートの出力言語（PDF・HTML）

Markdown で保存したレポートは、診断概要などの見出しと表の列名が日本語で出力されます。エグゼクティブサマリーの節は表示言語に従います。

ライセンス表示

設定画面の「ライセンス」では、現在のプラン（Free または Pro）を確認できます。

表示項目内容
現在のプランFree または Pro
Pro にアップグレード / 復元Microsoft Store での購入と、購入情報の確認（復元）を行います。

Pro 版へのアップグレードは Microsoft Store から行います。詳しくは Free と Pro の違い を参照してください。

外部リンク

設定画面の「情報」の欄には、以下のボタンが用意されています。「利用規約を表示」はアプリ内で利用規約を表示し、そのほかは外部ページをブラウザーで開きます。

  • 利用規約を表示: 利用規約を確認できます。
  • プライバシーポリシー: データの取り扱いに関する方針を確認できます。
  • マニュアル: このユーザーマニュアルを開きます。
  • 製品サイト: SecureNavigator の製品情報ページを開きます。
  • サポート: サポートのページをブラウザーで開きます。よくある問題と対処方法は トラブルシューティング を参照してください。

アプリのバージョンは、「情報」の欄に「バージョン x.y.z」の形で表示されます。

Chapter 7: Settings

Language switching, license, external links

Settings Screen Overview

The Settings dialog lets you check the display language, license, and external links. Open it with the settings button on the main screen.

Language Switching

SecureNavigator supports Japanese and English. You can choose the display language in the Settings screen ("Display Language") from "日本語" (Japanese) and "English".

Changing the language is reflected in:

  • All application UI text
  • Hearing screen question text and answer options
  • Results screen content
  • Report output language (PDF and HTML)

A report saved as Markdown outputs its headings, such as the assessment overview, and its table column names in Japanese. The Executive Summary section follows the display language.

License Display

The license section of the Settings screen shows your current plan (Free or Pro).

ItemDescription
Current PlanFree or Pro
Upgrade to Pro / RestorePurchase through the Microsoft Store and re-check your purchase (restore).

Upgrading to Pro is done through the Microsoft Store. See Free vs Pro Features for details.

External Links

The Information section of the Settings screen provides the following buttons. "View Terms" shows the terms of use in the app; the others open external pages in your web browser.

  • View Terms: Review the terms of use.
  • Privacy Policy: Review how your data is handled.
  • User Manual: Opens this user manual.
  • Product Website: Opens the SecureNavigator product information page.
  • Support: Opens the support page in your web browser. For common issues and solutions, see Troubleshooting.

The app version appears in the Information section as "Version x.y.z".
